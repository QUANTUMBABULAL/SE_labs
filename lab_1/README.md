Problem Statement #41: OpenAPI Mock Server Generator
📌 Project Overview

The OpenAPI Mock Server Generator is a developer productivity tool that ingests OpenAPI 3.0 YAML or JSON specifications and automatically creates dynamic mock REST API endpoints.

The system generates randomized JSON responses that comply with the schemas defined in the OpenAPI specification. It also supports schema validation and configurable response latency to help API Developers and QA Engineers test applications without requiring the actual backend service.

🎯 Lab Objectives
Elicit and document functional and non-functional requirements.
Define measurable acceptance criteria for requirements.
Identify system actors and use cases.
Create a UML Use-Case Diagram.
Apply «include» and «extend» relationships.
Create a detailed Use-Case Flow Specification.
