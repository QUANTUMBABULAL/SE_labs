# Software Engineering Lab 02: Agile Backlog Creation & Sprint Simulation in Jira

**Problem Statement #41: OpenAPI Mock Server Generator**

The Lab 1 requirements (FR-001 to FR-005, NFR-001 and NFR-002) were turned into an agile backlog in Jira. The backlog has 3 epics and 8 user stories with Fibonacci story points, split across two sprints.

## Epics

| Epic | Stories | Story points |
|------|---------|--------------|
| SCRUM-1 Specification Upload & Validation | SCRUM-4, 5, 6 | 10 |
| SCRUM-2 Mock Endpoint Generation | SCRUM-7, 8 | 13 |
| SCRUM-3 Request Handling & Network Simulation | SCRUM-9, 10, 11 | 11 |

- **Sprint 1** (18 SP): upload, validate and generate endpoints (SCRUM-4, 5, 6, 7)
- **Sprint 2** (16 SP): schema-compliant responses, routing, latency and the load target (SCRUM-8, 9, 10, 11)
